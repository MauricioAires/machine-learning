# Notes

[LangSmith](https://smith.langchain.com/) é basicamente um espaço em nuvem que pode ser usado para visualizar minha aplicação e realizar depuração tudo isso sem pagar nenhum valor.

Comando para criar uma aplicação de exemplo
npx @langchain/langgraph-cli new

npx @langchain/langgraph-cli@latest dev

Langchain trabalha com grafos
