Treinar uma rede neural significa ensinar a rede a identificar padrões nos dados que você fornece. Pense nela como um aluno que precisa aprender a classificar informações.

No exemplo dado, você alimenta a rede neural com dados de pessoas (nome, idade, cor, localização) e também informa a qual categoria cada pessoa pertence. A rede, então, tenta encontrar relações entre as características das pessoas e suas categorias. 

O processo de "treinamento" envolve ajustar internamente os "neurônios" da rede (que são como pequenas calculadoras matemáticas) para que ela possa prever a categoria correta para novas pessoas que ela nunca viu antes. Quanto mais dados você fornecer para a rede "estudar", mais precisa ela se tornará em suas previsões.

No exemplo, a rede aprende a partir de dados como:

*   Erick: 30 anos
*   Ana: 25 anos
*   Carlos: 40 anos

E, ao receber dados de uma nova pessoa, ela tentará determinar a qual categoria essa pessoa tem mais probabilidade de pertencer, com base no que aprendeu com os dados anteriores. A quantidade de neurônios usados pode ser ajustada para melhorar a precisão da rede.
